# Candor Privacy Policy

The published privacy policy for the **Candor** iOS app (an AI workplace-communication coach).

- Live URL: https://manmeetsethi.github.io/candor-privacy-policy/
- Source: `index.html` + `styles.css` (static, GitHub Pages).

Use the live URL as the Privacy Policy URL in the Meta app (Settings -> Basic) and in
App Store Connect. Update the "Last updated" date in `index.html` whenever the policy
changes, and keep it consistent with the App Store privacy "nutrition labels".
